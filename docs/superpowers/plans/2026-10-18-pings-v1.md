# Pings v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Pings mod (quick ping + 5-category ping wheel, server-decided recipients, Locator-Bar-colored markers with off-screen arrows) for Minecraft 26.3 on Fabric and NeoForge.

**Architecture:** One Stonecutter-preprocessed source set (`src/main/java`) built into two version nodes, `26.3-fabric` and `26.3-neoforge`, mirroring `bedbugs`. All game logic lives in loader-agnostic classes. The per-loader code is only registration glue in four entrypoint classes (`PingsFabric`, `PingsFabricClient`, `PingsNeoForge`, `PingsNeoForgeClient`) plus `ModLoaderAccess`. Pure logic (rate limiting, recipient selection, config parsing, ping expiry, wheel/marker math, payload codecs) sits in small classes that take injected inputs, so JUnit tests run without starting Minecraft (the same pattern as `bedbugs`' `HighlightTracker`).

**Tech Stack:** Java 25, Gradle 9.8 wrapper, Stonecutter 0.9.8, loom-back-compat 0.4.2 (Fabric Loom), NeoForge ModDev 2.0.147, Fabric API 0.163.0+26.3, NeoForge 26.3.0.88, JUnit 5.11.3.

**Spec:** `docs/superpowers/specs/2026-10-18-pings-design.md`

## Global Constraints

- Minecraft **26.3 only**; loaders **Fabric + NeoForge** only. No Forge, no Architectury, no other cross-loader library.
- Mod id `pings`, mod name `Pings`, package `com.github._0x00acab.pings`, version `0.1.0`.
- Java 25 (the toolchain `bedbugs` uses for 26.x).
- Ping lifetime **10 seconds**. Entity pings follow the entity for that same 10 seconds.
- Spam control defaults: **1 s** base cooldown; **more than 4 attempts in a 3 s rolling window** triggers a lockout that clears after a quiet period (default 5 s). All of these are configurable.
- Wheel categories, in this order: **Danger, Look Here, Come Here, Need Help, Mining/Resource**. Quick ping uses the reserved `PLAIN` category.
- Marker color = the sender's vanilla Locator Bar color. Category is shown only by the icon, never by color.
- The server decides recipients: the sender's scoreboard team if they have one, otherwise players within a configurable radius.
- Mod icon: the user-provided `assets/icon.png` (512×512), moved to `src/main/resources/assets/pings/icon.png`.
- License: CC0-1.0 (copied from `bedbugs`; the spec does not name one).

## Deviations from the spec (approve or reject before execution)

1. **Markers are drawn on the HUD at the projected screen position, not as world-space billboards.** Each loader then needs one HUD hook instead of a world-render hook plus a HUD hook. The 26.3 world-render pipeline is the API that has changed most from version to version, so avoiding it removes the biggest compile risk. Markers also keep a constant size, so a ping 200 blocks away stays readable. The diamond still appears exactly where the target is. The one difference: it does not shrink with distance.
2. **Lifetime is a client-side 10 s timer that starts when the ping arrives, not a server-stamped timestamp.** Client and server clocks are not synchronized, so an absolute timestamp would expire pings early or late on players whose clocks are off.
3. **Recipients only include players in the sender's dimension.** A ping position from another dimension cannot be drawn meaningfully.
4. **Default keys: quick ping `G`, wheel `R`.** `G` is unbound in vanilla. Middle mouse was rejected because vanilla uses it for pick-block.
5. **Config is `config/pings.properties`** (plain `java.util.Properties`, no config library).

## Review Focus

1. **Entity pinged, then it dies or unloads before 10 s:** the marker should stay at the last known position, not crash or jump to 0,0,0. Pinned in Task 9 (`ActivePing.renderPosition`).
2. **A modified client sends NaN coordinates, a target 10 000 blocks away, or an unknown category id:** the server should drop it silently with no broadcast and no exception. Pinned in Task 2 (`PingCategory.byId`) and Task 6 (`isValidTarget`).
3. **A player changes dimension or disconnects while pings are active:** the old pings should disappear, not draw at the same coordinates in the new world. Pinned in Task 7 (`PingTracker.ensureLevel`).
4. **A player holds the quick-ping key down:** the server should lock them out after the burst, and stay locked while they keep trying. Pinned in Task 4.
5. **A ping directly behind the camera:** the arrow should sit at the bottom edge pointing down, not at screen center or NaN. Pinned in Task 9 (`MarkerMath`).

package com.github._0x00acab.pings;

import java.io.IOException;
import java.io.Reader;
import java.io.Writer;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Properties;

public record PingsConfig(
    long cooldownMillis,
    int burstLimit,
    long burstWindowMillis,
    long lockoutQuietMillis,
    double noTeamRadius,
    double maxPingDistance
) {
    public static final PingsConfig DEFAULTS = new PingsConfig(1000L, 4, 3000L, 5000L, 128.0, 256.0);

    public static PingsConfig load(Path file) {
        if (!Files.exists(file)) {
            save(file, DEFAULTS);
            return DEFAULTS;
        }
        Properties props = new Properties();
        try (Reader reader = Files.newBufferedReader(file)) {
            props.load(reader);
        } catch (IOException e) {
            PingsMod.LOGGER.warn("Could not read {}, using defaults", file, e);
            return DEFAULTS;
        }
        return new PingsConfig(
            readLong(props, "cooldown_millis", DEFAULTS.cooldownMillis, 0),
            (int) readLong(props, "burst_limit", DEFAULTS.burstLimit, 1),
            readLong(props, "burst_window_millis", DEFAULTS.burstWindowMillis, 0),
            readLong(props, "lockout_quiet_millis", DEFAULTS.lockoutQuietMillis, 0),
            readPositiveDouble(props, "no_team_radius", DEFAULTS.noTeamRadius),
            readPositiveDouble(props, "max_ping_distance", DEFAULTS.maxPingDistance));
    }

    private static void save(Path file, PingsConfig config) {
        Properties props = new Properties();
        props.setProperty("cooldown_millis", Long.toString(config.cooldownMillis));
        props.setProperty("burst_limit", Integer.toString(config.burstLimit));
        props.setProperty("burst_window_millis", Long.toString(config.burstWindowMillis));
        props.setProperty("lockout_quiet_millis", Long.toString(config.lockoutQuietMillis));
        props.setProperty("no_team_radius", Double.toString(config.noTeamRadius));
        props.setProperty("max_ping_distance", Double.toString(config.maxPingDistance));
        try {
            Files.createDirectories(file.getParent());
            try (Writer writer = Files.newBufferedWriter(file)) {
                props.store(writer, "Pings server settings. Delete a line to restore its default.");
            }
        } catch (IOException e) {
            PingsMod.LOGGER.warn("Could not write default config to {}", file, e);
        }
    }

    private static long readLong(Properties props, String key, long fallback, long min) {
        String raw = props.getProperty(key);
        if (raw == null) {
            return fallback;
        }
        try {
            long value = Long.parseLong(raw.trim());
            if (value >= min) {
                return value;
            }
        } catch (NumberFormatException ignored) {
        }
        PingsMod.LOGGER.warn("Ignoring invalid {}={} in pings config", key, raw);
        return fallback;
    }

    private static double readPositiveDouble(Properties props, String key, double fallback) {
        String raw = props.getProperty(key);
        if (raw == null) {
            return fallback;
        }
        try {
            double value = Double.parseDouble(raw.trim());
            if (Double.isFinite(value) && value > 0) {
                return value;
            }
        } catch (NumberFormatException ignored) {
        }
        PingsMod.LOGGER.warn("Ignoring invalid {}={} in pings config", key, raw);
        return fallback;
    }
}

package com.github._0x00acab.pings.server;

import com.github._0x00acab.pings.PingsConfig;
import java.util.ArrayDeque;
import java.util.HashMap;
import java.util.Map;
import java.util.UUID;
import java.util.function.LongSupplier;

public final class PingRateLimiter {
    public enum Result { ACCEPTED, COOLDOWN, LOCKED_OUT }

    private final PingsConfig config;
    private final LongSupplier clock;
    private final Map<UUID, State> states = new HashMap<>();

    public PingRateLimiter(PingsConfig config, LongSupplier clockMillis) {
        this.config = config;
        this.clock = clockMillis;
    }

    public Result tryPing(UUID player) {
        long now = clock.getAsLong();
        forgetIdle(now);
        State state = states.computeIfAbsent(player, id -> new State());

        if (state.lockedOut && now - state.lastAttempt >= config.lockoutQuietMillis()) {
            state.lockedOut = false;
            state.attempts.clear();
        }
        state.lastAttempt = now;
        if (state.lockedOut) {
            return Result.LOCKED_OUT;
        }

        while (!state.attempts.isEmpty() && now - state.attempts.peekFirst() >= config.burstWindowMillis()) {
            state.attempts.pollFirst();
        }
        state.attempts.addLast(now);
        if (state.attempts.size() > config.burstLimit()) {
            state.lockedOut = true;
            return Result.LOCKED_OUT;
        }

        if (state.hasAccepted && now - state.lastAccepted < config.cooldownMillis()) {
            return Result.COOLDOWN;
        }
        state.hasAccepted = true;
        state.lastAccepted = now;
        return Result.ACCEPTED;
    }

    int trackedCount() {
        return states.size();
    }

    private void forgetIdle(long now) {
        long idleAfter = Math.max(config.cooldownMillis(), Math.max(config.burstWindowMillis(), config.lockoutQuietMillis()));
        states.values().removeIf(state -> now - state.lastAttempt >= idleAfter);
    }

    private static final class State {
        final ArrayDeque<Long> attempts = new ArrayDeque<>();
        boolean hasAccepted;
        long lastAccepted;
        long lastAttempt;
        boolean lockedOut;
    }
}

package com.github._0x00acab.pings.server;

import java.util.ArrayList;
import java.util.List;
import java.util.Objects;
import net.minecraft.world.phys.Vec3;

public final class RecipientResolver {
    public record Candidate<P>(P player, TeamId team, String dimension, Vec3 position) {}

    private RecipientResolver() {}

    public static <P> List<P> resolve(Candidate<P> sender, List<Candidate<P>> online, double noTeamRadius) {
        double radiusSqr = noTeamRadius * noTeamRadius;
        List<P> recipients = new ArrayList<>();
        boolean senderIncluded = false;
        for (Candidate<P> candidate : online) {
            if (!candidate.dimension().equals(sender.dimension())) {
                continue;
            }
            boolean isSender = Objects.equals(candidate.player(), sender.player());
            boolean reached = sender.team() != null
                ? sender.team().equals(candidate.team())
                : candidate.position().distanceToSqr(sender.position()) <= radiusSqr;
            if (isSender || reached) {
                recipients.add(candidate.player());
                senderIncluded |= isSender;
            }
        }
        if (!senderIncluded) {
            recipients.add(0, sender.player());
        }
        return recipients;
    }
}

package com.github._0x00acab.pings.server;

import com.github._0x00acab.pings.ModLoaderAccess;
import com.github._0x00acab.pings.PingCategory;
import com.github._0x00acab.pings.PingsConfig;
import com.github._0x00acab.pings.network.PingBroadcastPayload;
import com.github._0x00acab.pings.network.PingRequestPayload;
import java.util.List;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.phys.Vec3;

public final class PingRequestHandler {
    private final PingsConfig config;
    private final PingRateLimiter limiter;
    private final TeamProvider teams;

    public PingRequestHandler(PingsConfig config, PingRateLimiter limiter, TeamProvider teams) {
        this.config = config;
        this.limiter = limiter;
        this.teams = teams;
    }

    public void handle(ServerPlayer sender, PingRequestPayload request) {
        PingCategory category = PingCategory.byId(request.categoryId());
        if (category == null) {
            return;
        }

        Vec3 target = request.position();
        int entityId = PingRequestPayload.NO_ENTITY;
        if (request.entityId() != PingRequestPayload.NO_ENTITY) {
            Entity entity = sender.level().getEntity(request.entityId());
            if (entity != null && !entity.isRemoved()) {
                target = entity.position().add(0, entity.getBbHeight() + PingBroadcastPayload.ENTITY_MARKER_OFFSET, 0);
                entityId = entity.getId();
            }
        }

        if (!isValidTarget(sender.getEyePosition(), target, config.maxPingDistance())) {
            return;
        }
        if (limiter.tryPing(sender.getUUID()) != PingRateLimiter.Result.ACCEPTED) {
            return;
        }

        PingBroadcastPayload broadcast = new PingBroadcastPayload(target, entityId, category.ordinal(), SenderColor.of(sender));
        for (ServerPlayer recipient : recipients(sender)) {
            ModLoaderAccess.INSTANCE.sendToPlayer(recipient, broadcast);
        }
    }

    static boolean isValidTarget(Vec3 eye, Vec3 target, double maxDistance) {
        return Double.isFinite(target.x) && Double.isFinite(target.y) && Double.isFinite(target.z)
            && eye.distanceToSqr(target) <= maxDistance * maxDistance;
    }

    private List<ServerPlayer> recipients(ServerPlayer sender) {
        List<RecipientResolver.Candidate<ServerPlayer>> online = sender.level().getServer().getPlayerList().getPlayers()
            .stream()
            .map(this::candidate)
            .toList();
        return RecipientResolver.resolve(candidate(sender), online, config.noTeamRadius());
    }

    private RecipientResolver.Candidate<ServerPlayer> candidate(ServerPlayer player) {
        return new RecipientResolver.Candidate<>(player, teams.getTeam(player), player.level().dimension().toString(), player.position());
    }
}

package com.github._0x00acab.pings.client;

import com.github._0x00acab.pings.PingCategory;
import java.util.ArrayList;
import java.util.List;
import java.util.function.LongSupplier;
import net.minecraft.world.phys.Vec3;

public final class PingTracker {
    public static final long LIFETIME_MILLIS = 10_000L;
    public static final int MAX_ACTIVE = 64;

    private final LongSupplier clock;
    private final List<ActivePing> pings = new ArrayList<>();
    private Object level;

    public PingTracker(LongSupplier clockMillis) {
        this.clock = clockMillis;
    }

    // Identity, not equals: a reconnect or dimension change creates a new level object.
    public void ensureLevel(Object level) {
        if (level == null || this.level != level) {
            pings.clear();
            this.level = level;
        }
    }

    public void add(Vec3 position, int entityId, PingCategory category, int color) {
        if (pings.size() >= MAX_ACTIVE) {
            pings.removeFirst();
        }
        pings.add(new ActivePing(position, entityId, category, color, clock.getAsLong() + LIFETIME_MILLIS));
    }

    public List<ActivePing> active() {
        long now = clock.getAsLong();
        pings.removeIf(ping -> now >= ping.expiresAtMillis());
        return List.copyOf(pings);
    }
}

package com.github._0x00acab.pings.client;

public final class WheelMath {
    private WheelMath() {}

    public static int sectorAt(double dx, double dy, int sectors, double deadZone) {
        if (dx * dx + dy * dy < deadZone * deadZone) {
            return -1;
        }
        double angle = Math.atan2(dx, -dy);
        if (angle < 0) {
            angle += 2 * Math.PI;
        }
        double width = 2 * Math.PI / sectors;
        return (int) Math.floor((angle + width / 2) / width) % sectors;
    }

    public static double sectorCenterAngle(int index, int sectors) {
        return index * 2 * Math.PI / sectors;
    }
}

- [ ] **Step 7: Implement `PingTargeting.java`**

Vanilla's `minecraft.hitResult` stops at interaction reach (~4.5 blocks), so pings use their own 256-block raycast. It returns the nearest entity in front of the first solid block, otherwise the block hit, otherwise `null` (looking at sky).

```java
package com.github._0x00acab.pings.client;

import com.github._0x00acab.pings.PingCategory;
import com.github._0x00acab.pings.network.PingRequestPayload;
import net.minecraft.client.Minecraft;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.entity.projectile.ProjectileUtil;
import net.minecraft.world.phys.AABB;
import net.minecraft.world.phys.EntityHitResult;
import net.minecraft.world.phys.HitResult;
import net.minecraft.world.phys.Vec3;

public final class PingTargeting {
    public static final double MAX_DISTANCE = 256.0;

    private PingTargeting() {}

    public static PingRequestPayload target(Minecraft minecraft, PingCategory category) {
        Entity camera = minecraft.getCameraEntity();
        if (camera == null || minecraft.level == null) {
            return null;
        }
        float partial = minecraft.getDeltaTracker().getGameTimeDeltaPartialTick(true);
        HitResult blockHit = camera.pick(MAX_DISTANCE, partial, false);
        Vec3 eye = camera.getEyePosition(partial);
        Vec3 look = camera.getViewVector(partial);
        double reach = blockHit.getType() == HitResult.Type.MISS ? MAX_DISTANCE : blockHit.getLocation().distanceTo(eye);

        Vec3 end = eye.add(look.scale(reach));
        AABB sweep = camera.getBoundingBox().expandTowards(look.scale(reach)).inflate(1.0);
        EntityHitResult entityHit = ProjectileUtil.getEntityHitResult(camera, eye, end, sweep,
            entity -> !entity.isSpectator() && entity.isPickable(), reach * reach);

        if (entityHit != null) {
            Entity entity = entityHit.getEntity();
            return new PingRequestPayload(entity.position(), entity.getId(), category.ordinal());
        }
        if (blockHit.getType() == HitResult.Type.BLOCK) {
            return new PingRequestPayload(blockHit.getLocation(), PingRequestPayload.NO_ENTITY, category.ordinal());
        }
        return null;
    }
}

    public static final KeyMapping WHEEL_KEY = new KeyMapping("key.pings.ping_wheel", GLFW.GLFW_KEY_R, KeyMapping.Category.MULTIPLAYER);

    private static Consumer<PingRequestPayload> sender = request -> {};

    private PingClient() {}

    public static void init(Consumer<PingRequestPayload> serverSender) {
        sender = serverSender;
    }

    public static void tick(Minecraft minecraft) {
        TRACKER.ensureLevel(minecraft.level);
        if (minecraft.player == null) {
            return;
        }
        while (QUICK_PING_KEY.consumeClick()) {
            sendPing(minecraft, PingCategory.PLAIN);
        }
        while (WHEEL_KEY.consumeClick()) {
            if (minecraft.gui.screen() == null) {

        }

        PingRequestPayload request = PingTargeting.target(minecraft, category);
        if (request != null) {
            sender.accept(request);
        }
    }

    public static void receive(PingBroadcastPayload payload) {
        PingCategory category = PingCategory.byId(payload.categoryId());
        if (category != null) {
            TRACKER.add(payload.position(), payload.entityId(), category, payload.color());
        }
    }

        lastMouseY = mouseY;
        PingCategory hovered = hovered(mouseX, mouseY);

        int centerY = height / 2;

            graphics.fill(x - TILE_HALF, y - TILE_HALF, x + TILE_HALF, y + TILE_HALF, selected ? 0xC0FFFFFF : 0x90000000);
            graphics.blitSprite(RenderPipelines.GUI_TEXTURED, category.sprite(), x - ICON / 2, y - ICON / 2, ICON, ICON);
            graphics.centeredText(font, Component.translatable(category.translationKey()), x, y + TILE_HALF + 3, selected ? 0xFFFFFF55 : 0xFFFFFFFF);
        }
    }

    @Override
    public boolean keyReleased(KeyEvent event) {
        if (holdKey.matches(event)) {
            commit(lastMouseX, lastMouseY);
            return true;
        }
        return super.keyReleased(event);
    }

    @Override
    public boolean mouseReleased(MouseButtonEvent event) {
        if (holdKey.matchesMouse(event)) {
            commit(event.x(), event.y());
            return true;
        }
        return super.mouseReleased(event);
    }

    public boolean mouseClicked(MouseButtonEvent event, boolean doubleClick) {

            return true;

        return super.mouseClicked(event, doubleClick);

        PingCategory choice = hovered(mouseX, mouseY);
        onClose();
        if (choice != null) {
            PingClient.sendPing(minecraft, choice);
        }
    }

package com.github._0x00acab.pings.client;

import java.util.Locale;

public final class MarkerMath {
    public record Placement(double x, double y, boolean onScreen, double arrowAngle) {}

    private MarkerMath() {}

    public static Placement place(double ndcX, double ndcY, boolean inFront, int width, int height, int margin) {
        double screenX = (ndcX + 1) / 2 * width;
        double screenY = (1 - ndcY) / 2 * height;
        if (inFront && screenX >= margin && screenX <= width - margin && screenY >= margin && screenY <= height - margin) {
            return new Placement(screenX, screenY, true, 0);
        }

        double centerX = width / 2.0;
        double centerY = height / 2.0;
        double dx = screenX - centerX;
        double dy = screenY - centerY;
        // Points behind the camera project mirrored through the center.
        if (!inFront) {
            dx = -dx;
            dy = -dy;
        }
        if (dx == 0 && dy == 0) {
            dy = 1;
        }
        double scale = Math.min((centerX - margin) / Math.abs(dx), (centerY - margin) / Math.abs(dy));
        return new Placement(centerX + dx * scale, centerY + dy * scale, false, Math.atan2(dy, dx));
    }

    public static String formatDistance(double blocks) {
        return blocks < 10 ? String.format(Locale.ROOT, "%.1fm", blocks) : Math.round(blocks) + "m";
    }
}

            Vec3 relative = target.subtract(cameraPos);
            boolean inFront = relative.x * forward.x() + relative.y * forward.y() + relative.z * forward.z() > 0;
            Vec3 ndc = minecraft.gameRenderer.projectPointToScreen(target);
            MarkerMath.Placement placement = MarkerMath.place(ndc.x, ndc.y, inFront, graphics.guiWidth(), graphics.guiHeight(), EDGE_MARGIN);
            String distance = MarkerMath.formatDistance(relative.length());
            if (placement.onScreen()) {
                drawDiamond(graphics, minecraft, placement, ping, distance);
            } else {
                drawArrow(graphics, minecraft, placement, ping.color(), distance);
            }
        }
    }

    private static Vec3 liveAnchor(ClientLevel level, ActivePing ping, float partial) {
        if (ping.entityId() == PingRequestPayload.NO_ENTITY) {
            return null;
        }
        Entity entity = level.getEntity(ping.entityId());
        if (entity == null || entity.isRemoved()) {
            return null;
        }
        return entity.getPosition(partial).add(0, entity.getBbHeight() + PingBroadcastPayload.ENTITY_MARKER_OFFSET, 0);
    }

    private static void drawDiamond(GuiGraphicsExtractor graphics, Minecraft minecraft, MarkerMath.Placement placement, ActivePing ping, String distance) {
        float x = (float) placement.x();
        float y = (float) placement.y();
        Matrix3x2fStack pose = graphics.pose();
        pose.pushMatrix();
        pose.translate(x, y);
        pose.rotate((float) (Math.PI / 4));
        frame(graphics, OUTLINE_HALF, ping.color());
        graphics.fill(-FILL_HALF, -FILL_HALF, FILL_HALF, FILL_HALF, ping.color());
        pose.popMatrix();

        int ix = Math.round(x);
        int iy = Math.round(y);
        if (ping.category() != PingCategory.PLAIN) {
            graphics.blitSprite(RenderPipelines.GUI_TEXTURED, ping.category().sprite(), ix - ICON / 2, iy - ICON / 2, ICON, ICON);
        }
        int diamondTop = (int) Math.ceil(OUTLINE_HALF * Math.sqrt(2));
        graphics.centeredText(minecraft.font, distance, ix, iy - diamondTop - minecraft.font.lineHeight - 1, TEXT_COLOR);
    }

    private static void frame(GuiGraphicsExtractor graphics, int half, int color) {
        graphics.fill(-half, -half, half, -half + 1, color);
        graphics.fill(-half, half - 1, half, half, color);
        graphics.fill(-half, -half + 1, -half + 1, half - 1, color);
        graphics.fill(half - 1, -half + 1, half, half - 1, color);
    }

    private static void drawArrow(GuiGraphicsExtractor graphics, Minecraft minecraft, MarkerMath.Placement placement, int color, String distance) {
        float x = (float) placement.x();
        float y = (float) placement.y();
        Matrix3x2fStack pose = graphics.pose();
        pose.pushMatrix();
        pose.translate(x, y);
        pose.rotate((float) placement.arrowAngle());
        graphics.fill(-6, -1, 2, 1, color);
        graphics.fill(0, -4, 2, 4, color);
        graphics.fill(2, -3, 4, 3, color);
        graphics.fill(4, -2, 6, 2, color);
        graphics.fill(6, -1, 7, 1, color);
        pose.popMatrix();

        int textX = Math.round(x - (float) Math.cos(placement.arrowAngle()) * 20);
        int textY = Math.round(y - (float) Math.sin(placement.arrowAngle()) * 14) - minecraft.font.lineHeight / 2;
        graphics.centeredText(minecraft.font, distance, textX, textY, TEXT_COLOR);
    }
}
```

`ClientLevel#getEntity(int)` is inherited from `Level`, and `getPosition(float)` gives the interpolated position, so tracked markers move smoothly between ticks.
